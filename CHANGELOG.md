# Changelog

## 1.1.0 — 2026-09-21

- Added Normal, Large, and Full-screen preview window sizes.
- Added native drag-to-resize support.
- Added Fit and 25%–400% image zoom controls.
- Replaced the purple interface accent with a high-contrast orange/amber palette.

- Initial Canvas SpeedGrader ZIP listing and in-page preview.
- Added text, code, image, and binary hex previews.
- Added ZIP64 metadata, CRC-32 checks, search, path warnings, and download limits.
