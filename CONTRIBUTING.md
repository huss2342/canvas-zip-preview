# Contributing

Bug reports and focused pull requests are welcome.

1. Fork the repository and create a small topic branch.
2. Make the change without adding runtime dependencies unless they are clearly necessary.
3. Run `npm test` and the JavaScript syntax checks.
4. Test the unpacked extension on a current Canvas SpeedGrader page.
5. Describe the Canvas environment and expected behavior without including student-identifying information.

Use only synthetic ZIP archives, filenames, screenshots, and course data in issues, tests, and pull requests. Never publish real student submissions or signed Canvas download URLs.
